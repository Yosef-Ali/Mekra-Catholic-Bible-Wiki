# አለኝ ብዙ ምስጋና

አለኝ ብዙ ምስጋና
አለኝ ብዙ ምሥጋና ላንተ ሚሰዋ ገና(2)
ምስጉን ነህ አንተ ሁሌ መልካም ስመ ገናና (2)

ልበል እንጂ አንተ መልካም ውለታህን እኔ አልረሳም
ላመስግንህ የእኔ ጌታ ሳልሰላች ጠዋት ማታ (2)

ገና ሳላውቅህ አወቅኽኝ
ለራስህ መርጠህ ቀባኸኝ
የልጅነት ሥልጣን ሰጥተህ የመንግስትህ ወራሽ አረከኝ
አገዛዝህ ምቹ ነው  አልሄድ እኔስ ወደሌላ
ግዛኝ አንተ ለዘላለም ሁንልኝ የኔ ከለላ

ያዘኝ አትልቀቀኝ እስከ መጨረሻ
ሌላ እኔ የለኝም ከክፉ መሸሻ
ላተወኝ ላትረሳኝ ቃል የገባህልኝ
አስበኝ አባቴ ከቶ እንዳትረሳኝ

ነህ አንተ የዘላለሜ ዕጣዬ ዕድል ፈንታዬ
ሆኛለሁ እኔ እድለኛ ስለሆንኩ ያንተ ጥገኛ

ለውለታህ ምላሽ ሚሆን
አጣሁኝ ፍጽም የሚመጥን
የቃላት መዓት ደርድሬ
ብዘምረው ምሥጋናህን
ከአእምሮዬ በላይ ነው
አምላኬ መልካምነትህ
ፈጽሞ ቃላት አይገልጸው
ላንተ ከቶ አይበቃህም

ያዘኝ አትልቀቀኝ እስከ መጨረሻ
ሌላ እኔ የለኝም ከክፉ መሸሻ
ላተወኝ ላትረሳኝ ቃል የገባህልኝ
አስበኝ አባቴ ከቶ እንዳትረሳኝ

ነህ አንተ የዘላለሜ ዕጣዬ ዕድል ፈንታዬ
ሆኛለሁ እኔ እድለኛ ስለሆንኩ ያንተ ጥገኛ

አለኝ ብዙ ምሥጋና ላንተ ሚሰዋ ገና(2)
ምስጉን ነህ አንተ ሁሌ መልካም ስመ ገናና (2)

ልበል እንጂ አንተ መልካም ውለታህን እኔ አልረሳም
ላመስግንህ የእኔ ጌታ ሳልሰላች ጠዋት ማታ (2)

ነህ አንተ የዘላለሜ ዕጣዬ ዕድል ፈንታዬ
ሆኛለሁ እኔ እድለኛ ስለሆንኩ ያንተ ጥገኛ
