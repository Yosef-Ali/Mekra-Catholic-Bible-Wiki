# የመጽሐፍ ቅዱስ ጽሑፍ ማረጋገጫ — መመሪያ

**ለክቡር አባት፣**

ይህ ማህደር በመተግበሪያው (Mekra) ውስጥ ያለው የመጽሐፍ ቅዱስ ጽሑፍ ከታተመው **የኤማሁስ ካቶሊካዊ መጽሐፍ ቅዱስ** ጋር በኮምፒዩተር ተነጻጽሮ የተገኙ ልዩነቶችን ይዟል። አብዛኞቹ ስሕተቶች (ከ60,000 በላይ የሥርዓተ ነጥብና የቃላት ስሕተቶች) አስቀድመው በራስ‑ሰር ተስተካክለዋል — ማስተካከያው ሁሉ የተወሰደው ከመጽሐፉ ራሱ ነው። እዚህ የቀሩት ግን **የሰው ዓይን የሚሹ** ነጥቦች ብቻ ናቸው።

## እንዴት እንደሚገመገም

1. ከ[ማውጫው](00-ማውጫ.md) አንድ መጽሐፍ ይምረጡ (ለእያንዳንዱ መጽሐፍ አንድ ፋይል አለ)።
2. እያንዳንዱ ረድፍ አንድ ጥቅስ ያመለክታል፦ ምዕራፍ፥ቁጥር።
3. የታተመውን መጽሐፍ ገልጠው ጥቅሱን ይመልከቱ።
4. በ**ውሳኔ** አምድ ላይ ይጻፉ፦
   - **✓** — መጽሐፉ ትክክል ነው፤ አፑ ይስተካከል።
   - **✗** — አፑ እንዳለ ይቆይ (ለምሳሌ የመጽሐፉ የኅትመት ስሕተት ከሆነ)።
   - ሌላ ማስተካከያ ካስፈለገ ትክክለኛውን ቃል ይጻፉ።

## የግምገማ ቅደም ተከተል (የተመከረ)

በቅዳሴና በጸሎት ጮክ ተብለው የሚነበቡት መጻሕፍት ቅድሚያ ይሰጣቸው፦

1. **ምዕራፍ ፩ — የሥርዓተ አምልኮ ልብ፦** የሉቃስ ወንጌል (266)፣ መዝሙረ ዳዊት (398)፣ የማቴዎስ ወንጌል (162)፣ የዮሐንስ ወንጌል (163)፣ የማርቆስ ወንጌል (174)።
2. **ምዕራፍ ፪ — የቅዳሴ ንባባት፦** የሐዋርያት ሥራ (249)፣ ትንቢተ ኢሳይያስ (478)፣ ወደ ሮሜ ሰዎች (173)፣ 1ኛ ወደ ቆሮንቶስ (141)፣ ኦሪት ዘፍጥረት (620)፣ ኦሪት ዘፀአት (266)።
3. **ምዕራፍ ፫ — ቀሪው፦** በመጀመሪያ አጫጭሮቹን መልእክቶች (ከ60 በታች ነጥብ ያላቸውን — በአንድ ቀን ይጠናቀቃሉ)፣ ከዚያ ትልልቆቹን (ሲራክ 656፣ ኤርምያስ 477፣ 2ኛ ነገሥት 563፣ ሕዝቅኤል 378) እና የታሪክ መጻሕፍትን።

## ማስታወሻዎች

- ንጽጽሩ የተሠራው ከታተመው መጽሐፍ **ዲጂታል ጽሑፍ** ጋር ነው፤ የኮምፒዩተሩ ንባብ አልፎ አልፎ ሊሳሳት ስለሚችል፣ ጥርጣሬ ሲኖር የታተመው መጽሐፍ ሁልጊዜ ወሳኝ ነው።
- የመጽሐፉ ጥንታዊ ፊደላት (ሠ፣ ሐ፣ ኀ፣ ጸ፣ ፀ፣ ዐ) ሆን ተብለው እንደታተሙ ተጠብቀዋል።
