# ትንቢተ ሶፎንያስ (Zephaniah) — የመጽሐፍ ቅዱስ ጽሑፍ ማረጋገጫ

**ቀን፦** 2026-07-04 · **የሚታዩ ነጥቦች፦** 40

«በመጽሐፉ» = በታተመው የኤማሁስ መጽሐፍ ቅዱስ ውስጥ ያለው ቃል። «በአፑ» = በመተግበሪያው ውስጥ ያለው ቃል።
እባክዎ የታተመውን መጽሐፍ እየተመለከቱ በ«ውሳኔ» አምድ ላይ ✓ (መጽሐፉ ትክክል)፣ ✗ (አፑ ትክክል) ወይም ማስታወሻ ይጻፉ።

| 2፥1 | ቃል ተለውጧል | እናንተ የማታፍሩ ሕዝብ ሆይ፥ በአንድነት ተሰብሰቡ፥ ተከማቹም፤ | በመጠበቂያዬ ላይ እቆማለሁ፥ በዐምባ ላይም እወጣለሁ፤ ምን እንደሚለኝና ስለአቤቱታዬም ምን መልስ እንደምሰጥ ለማየት እጠባበቃለሁ። |  |
| 2፥2 | ቃል ተለውጧል | ትእዛዝ ሳይወጣ፥ ቀኑም እንደ ገለባ ሳያልፍ፥ የጌታም ቁጣ ትኩሳት ሳይመጣባችሁ፥ የጌታም ቁጣ ቀን ሳይደርስባችሁ | ጌታም መለሰልኝ እንዲህም አለ፦ ራእዩን ጻፍ፤ የሚያነበው እንደሮጠ በጽላት ላይ በግልፅ አድርገው። |  |
| 2፥3 | ቃል ተለውጧል | እናንተ ፍርዱን የጠበቃችሁ፥ የምድር ትሑታን ሁሉ፥ ጌታን ፈልጉ፤ ጽድቅን ፈልጉ፥ ትሕትናን ፈልጉ፤ ምናልባት በጌታ ቁጣ ቀን ትሰወሩ ይሆናል። | ራእዩ ገና እስከ ተወሰነው ጊዜ ነው፥ ወደ ፍጻሜውም ይፈጥናል፤ እርሱም አይዋሽም፤ ቢዘገይም በእርግጥ ይመጣልና ጠብቀው፤ አይዘገይም። |  |
| 2፥4 | ቃል ተለውጧል | ጋዛ ሰው የማይኖርባት ትሆናለች፥ አስቀሎናም ትፈራርሳለች፤ አሽዶድ በቀትር ወደ ውጭ ያሳድዷታል፥ ዔቅሮንም ትነቀላለች። | እነሆ፥ እርሱ ኮርቷል፤ ነፍሱ በውስጡ ቅን አይደለችም፤ ጻድቅ ግን በእምነቱ በሕይወት ይኖራል። |  |
| 2፥5 | ቃል ተለውጧል | እናንተ በባሕር ዳር የምትኖሩ፥ የከሪታውያን ሕዝብ ወዮላችሁ! የፍልስጥኤማውያን ምድር ከነዓን ሆይ፥ የጌታ ቃል በእናንተ ላይ | በእርግጥ ወይን አታላይ |  |
| 2፥5 | ቃል ተለውጧል | የሚቀመጥብሽ እንዳይኖር አድርጌ አጠፋሻለሁ። | ትዕቢተኛ ሰው በቤቱ አርፎ አይቀመጥም፤ ስስቱን እንደ ሲኦል ያሰፋል፤ እርሱም እንደ ሞት አይጠግብም፤ አሕዛብንም ሁሉ ወደ እርሱ ይሰበስባል፥ ወገኖችንም ሁሉ ወደ እርሱ ያከማቻል። |  |
| 2፥6 | ቃል ተለውጧል | የባሕሩም ዳር የግጦሽ መሬት፥ የእረኞች መስክና የበጎች በረት ይሆናል። | እነዚህ ሁሉ። በእርሱ ባልሆነው ላይ እርሱ ለሚሰበስብ መከራውንም ለራሱ ለሚያበዛ ወዮለት! እስከ መቼ ነው? እያሉ ምሳሌ አይመስሉበትምን? አባባልስ አያነሡበትም? |  |
| 2፥7 | ቃል ተለውጧል | የባሕሩም ዳር ለይሁዳ ቤት ትሩፍ ይሆናል፥ በዚያም ይሰማራሉ፤ በአስቀሎና ቤቶች ውስጥ ማታ ይተኛሉ፤ ጌታ አምላካቸው ይጐበኛቸዋልና፥ ምርኮአቸውንም ይመልሳል። | አበዳሪዎችህ ድንገት አይነሡምን? የሚያንቀጠቅጡህ አይነቁምን? ለእነርሱም ብዝበዛ ትሆናለህ። |  |
| 2፥8 | ቃል ተለውጧል | የሞዓብን ማላገጥና የአሞንን ልጆች ስድብ ሰምቻለሁ፤ በሕዝቤም ላይ አላግጠዋል፥ በድንበራቸውም | አንተ ብዙ አሕዛብን በዝብዘሃልና፥ የሰውን ደም ስላፈሰስህ፥ በምድሪቱና በከተማይቱም በእርሷም በሚኖሩ ሁሉ |  |
| 2፥8 | ቃል ተለውጧል | ኮርተዋል። | ላደረግኸው ግፍ፥ ከአሕዛብ የቀሩት ሁሉ ይበዘብዙሃል። |  |
| 2፥9 | ቃል ተለውጧል | ስለዚህ የእስራኤል አምላክ የሠራዊት ጌታ እንዲህ ይላል፦ እኔ ሕያው ነኝና ሞዓብ እንደ ሰዶም፥ የአሞንም ልጆች እንደ ገሞራ ይሆናሉ፥ አረም እንደ ዋጠው ስፍራና እንደ ጨው ጉድጓድ ለዘለዓለምም ይጠፋሉ፤ የሕዝቤም ትሩፍ ይበዘብዛቸዋል፥ ከወገኔም የተረፉት ይወርሱአቸዋል። | ከክፉ ለመታደግ ጐጆውን በከፍታ ላይ ለሚያደርግ፥ ለቤቱ ክፉ ትርፍን ለሚሰበስብ ወዮለት! |  |
| 2፥10 | ቃል ተለውጧል | ከትዕቢታቸው የተነሣ የሚደርስባቸው ይህ ነው፤ በሠራዊት ጌታ ሕዝብ | ብዙ አሕዛብን ቆርጠህ ለቤትህ እፍረትን መክረሃል፤ በነፍስህም |  |
| 2፥10 | ቃል ተለውጧል | አላግጠዋልና፥ በኩራትም ተናግረዋልና። | ኃጢአትን አድርገሃል። |  |
| 2፥11 | ቃል ተለውጧል | ጌታ በእነርሱ ዘንድ የተፈራ ይሆናል፥ የምድርን አማልክት ሁሉ ያጠፋቸዋልና፤ የሕዝቦችም ደሴቶች ሁሉ ላይ የሚኖሩ ሰዎች፥ ሁሉም በያሉበት ሆነው ለእርሱ ይሰግዳሉ። | ድንጋይ ከግንብ ውስጥ ይጮኻል፤ እንጨትም ከወራጅ ይመልስለታል። |  |
| 2፥12 | ቃል ተለውጧል | እናንተም ኢትዮጵያውያን ደግሞ፥ በሰይፌ ትገደላላችሁ። | ከተማን በደም ለሚሠራ፥ ከተማንም በበደል ለሚመሠርት ወዮለት! |  |
| 2፥13 | ቃል ተለውጧል | እርሱም በሰሜን ላይ እጁን ይዘረጋል፥ አሦርንም ያጠፋል፥ ነነዌንም ያፈራርሳታል፥ እንደ ምድረ በዳም ደረቅ ያደርጋታል። | እነሆ፥ አሕዛብ ለእሳት እንደሚቃጠሉ፥ ሕዝቦችም ለከንቱነት እንደሚደክሙ ከሠራዊት ጌታ ከእግዚአብሔር ዘንድ የተደረገ አይደለምን? |  |
| 2፥14 | ቃል ተለውጧል | መንጎችም የምድርም አራዊት ሁሉ በውስጧ ይኖራሉ፥ ጉጉትና ጃርት በዓምዶችዋ መካከል ያድራሉ፥ ድምፅም በመስኮት ይጮኻል፥ በመድረኩ ላይ ጥፋት ይደርሳል የዝግባ እንጨት ሥራ ይገለጣልና። | ውኃ ባሕርን እንደሚከድን፥ ምድር የእግዚአብሔርን ክብር በማወቅ ትሞላለችና። |  |
| 2፥15 | ቃል ተለውጧል | ስጋት ሳይኖርባት የተቀመጠች ደስተኛይቱ ከተማ ይህች ናት፥ በልብዋም፦ “እኔ ነኝ፥ ከእኔም በቀር ሌላ የለም” ያለች፥ እንዴት አራዊት የሚመሰጉባት ባድማ ሆነች! በእርሷ በኩል የሚያልፈው ሁሉ እጁን እያወዛወዘ ያፏጫል። | ባልንጀራውን ለሚያጠጣ፥ ከፋቱም ለሚጨምርበት፥ እፍረቱን ያይ ዘንድ ለሚያሰክረው ወዮለት! |  |
