# 3ኛ የዮሐንስ መልእክት (3 John) — የመጽሐፍ ቅዱስ ጽሑፍ ማረጋገጫ

**ቀን፦** 2026-07-03 · **የሚታዩ ነጥቦች፦** 4

«በመጽሐፉ» = በታተመው የኤማሁስ መጽሐፍ ቅዱስ ውስጥ ያለው ቃል። «በአፑ» = በመተግበሪያው ውስጥ ያለው ቃል።
