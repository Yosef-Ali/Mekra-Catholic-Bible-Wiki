# 1ኛ የዮሐንስ መልእክት (1 John) — የመጽሐፍ ቅዱስ ጽሑፍ ማረጋገጫ

**ቀን፦** 2026-07-03 · **የሚታዩ ነጥቦች፦** 13

«በመጽሐፉ» = በታተመው የኤማሁስ መጽሐፍ ቅዱስ ውስጥ ያለው ቃል። «በአፑ» = በመተግበሪያው ውስጥ ያለው ቃል።
እባክዎ የታተመውን መጽሐፍ እየተመለከቱ በ«ውሳኔ» አምድ ላይ ✓ (መጽሐፉ ትክክል)፣ ✗ (አፑ ትክክል) ወይም ማስታወሻ ይጻፉ።
