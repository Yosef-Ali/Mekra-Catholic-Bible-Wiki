# ወደ ቆላስይስ (Colossians) — የመጽሐፍ ቅዱስ ጽሑፍ ማረጋገጫ

**ቀን፦** 2026-07-04 · **የሚታዩ ነጥቦች፦** 7

«በመጽሐፉ» = በታተመው የኤማሁስ መጽሐፍ ቅዱስ ውስጥ ያለው ቃል። «በአፑ» = በመተግበሪያው ውስጥ ያለው ቃል።
